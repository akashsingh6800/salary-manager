# AI Usage

AI tools were used selectively during development as a coding and review assistant.

### Areas where AI was used

* Reviewing the initial requirements and identifying edge cases.
* Discussing database and API design options.
* Reviewing code for readability and maintainability.
* Suggesting additional test scenarios.
* Reviewing SQL queries and performance considerations.
* Improving documentation.

### Example Prompts

* "Review this API design and point out any issues or edge cases."
* "Review this SQLAlchemy query for correctness and performance."
* "Suggest meaningful tests for these API endpoints."
* "Review this code for readability and maintainability."
* "What performance considerations should I consider for 10,000 employees?"

AI-generated suggestions were reviewed and adapted before implementation. Final decisions regarding architecture, technology, implementation, and scope were made by the developer.
